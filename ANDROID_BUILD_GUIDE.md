# Android App Build Guide

This guide will help you build and publish the Household Routine Manager Android app.

## Prerequisites

1. **Android Studio** (latest version)
   - Download from: https://developer.android.com/studio
   - Install Android SDK (API 33+ recommended)

2. **Java Development Kit (JDK)**
   - JDK 17 or higher
   - Android Studio usually includes this

3. **Node.js** (already installed)
   - Version 18+ required

## Project Structure

The Android app is located in the `android/` directory. This is a native Android project generated by Capacitor.

## Development Workflow

### 1. Build Web App

First, build your web app:

```bash
npm run build
```

This creates the `dist/` folder with your optimized web assets.

### 2. Sync to Android

Sync the web assets to the Android project:

```bash
npm run cap:sync
```

Or use the combined command:

```bash
npm run cap:build
```

This will:
- Copy web assets from `dist/` to `android/app/src/main/assets/public/`
- Update Capacitor plugins
- Sync native dependencies

### 3. Open in Android Studio

Open the Android project in Android Studio:

```bash
npm run cap:open:android
```

Or manually:
```bash
npx cap open android
```

### 4. Run on Device/Emulator

In Android Studio:
1. Connect an Android device via USB (enable USB debugging)
2. Or create/start an Android emulator
3. Click the "Run" button (green play icon) or press `Shift+F10`

## Building Release APK/AAB

### Option 1: Build in Android Studio (Recommended)

1. Open the project in Android Studio (`npm run cap:open:android`)
2. Go to **Build** → **Generate Signed Bundle / APK**
3. Choose **Android App Bundle (AAB)** for Play Store or **APK** for direct distribution
4. Create a new keystore or use existing one
5. Fill in keystore details
6. Select **release** build variant
7. Click **Finish**

The signed APK/AAB will be generated in `android/app/release/`

### Option 2: Build from Command Line

#### Generate Keystore (first time only)

```bash
keytool -genkey -v -keystore household-routine-manager.keystore -alias household-routine-manager -keyalg RSA -keysize 2048 -validity 10000
```

Store the keystore file securely and remember the password!

#### Configure Signing

Create `android/key.properties`:

```properties
storePassword=your_keystore_password
keyPassword=your_key_password
keyAlias=household-routine-manager
storeFile=../household-routine-manager.keystore
```

**⚠️ Important:** Add `key.properties` to `.gitignore` (already done)

#### Update build.gradle

The `android/app/build.gradle` should already have signing config. If not, add:

```gradle
android {
    ...
    signingConfigs {
        release {
            def keystorePropertiesFile = rootProject.file("key.properties")
            def keystoreProperties = new Properties()
            if (keystorePropertiesFile.exists()) {
                keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
                storeFile file(keystoreProperties['storeFile'])
                storePassword keystoreProperties['storePassword']
                keyAlias keystoreProperties['keyAlias']
                keyPassword keystoreProperties['keyPassword']
            }
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
            proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
        }
    }
}
```

#### Build Release APK

```bash
cd android
./gradlew assembleRelease
```

APK will be at: `android/app/build/outputs/apk/release/app-release.apk`

#### Build Release AAB (for Play Store)

```bash
cd android
./gradlew bundleRelease
```

AAB will be at: `android/app/build/outputs/bundle/release/app-release.aab`

## Customizing App Icons

### Current Icons

Default Capacitor icons are in:
- `android/app/src/main/res/mipmap-*/ic_launcher.png`
- `android/app/src/main/res/mipmap-*/ic_launcher_round.png`

### Generate New Icons

1. Create your app icon (1024x1024px PNG)
2. Use Android Asset Studio: https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html
3. Upload your icon and download the generated icons
4. Replace files in `android/app/src/main/res/mipmap-*/`

Or use Capacitor's icon generator:
```bash
npx @capacitor/assets generate --iconBackgroundColor '#6366f1' --iconBackgroundColorDark '#4f46e5' --splashBackgroundColor '#6366f1' --splashBackgroundColorDark '#4f46e5'
```

## Customizing Splash Screen

Splash screen images are in:
- `android/app/src/main/res/drawable*/splash.png`

Configuration is in `capacitor.config.ts`:

```typescript
plugins: {
  SplashScreen: {
    launchShowDuration: 2000,
    launchAutoHide: true,
    backgroundColor: '#6366f1',
    // ...
  }
}
```

## Publishing to Google Play Store

### 1. Create Google Play Developer Account

- Go to: https://play.google.com/console
- Pay one-time $25 registration fee
- Complete account setup

### 2. Create New App

1. Click **Create app**
2. Fill in app details:
   - App name: "Household Routine Manager"
   - Default language: English
   - App or game: App
   - Free or paid: Free
   - Declarations: Accept all

### 3. Prepare Store Listing

Required assets:
- **App icon**: 512x512px PNG
- **Feature graphic**: 1024x500px PNG
- **Screenshots**: At least 2 (phone, tablet)
- **Short description**: Max 80 characters
- **Full description**: Max 4000 characters
- **Privacy Policy URL**: Required for apps with user data

### 4. Upload AAB

1. Go to **Production** → **Create new release**
2. Upload your signed AAB file (`app-release.aab`)
3. Add release notes
4. Click **Review release**

### 5. Complete Content Rating

- Fill out content rating questionnaire
- Submit for rating (usually instant)

### 6. Set Up Pricing & Distribution

- Select countries for distribution
- Set app as free
- Accept export compliance

### 7. Submit for Review

- Review all sections
- Click **Submit for review**
- Wait 1-3 days for approval

## Updating the App

When you make changes:

1. **Update web app:**
   ```bash
   npm run build
   ```

2. **Sync to Android:**
   ```bash
   npm run cap:sync
   ```

3. **Update version:**
   - Update `version` in `package.json`
   - Update `versionCode` and `versionName` in `android/app/build.gradle`:
     ```gradle
     android {
         defaultConfig {
             versionCode 2  // Increment for each release
             versionName "1.0.1"  // Semantic versioning
         }
     }
     ```

4. **Build new release:**
   - Follow "Building Release APK/AAB" steps above

5. **Upload to Play Store:**
   - Create new release in Play Console
   - Upload new AAB
   - Add release notes
   - Submit for review

## Troubleshooting

### Build Errors

**Error: "SDK location not found"**
- Create `android/local.properties`:
  ```properties
  sdk.dir=/path/to/Android/sdk
  ```
- Or set in Android Studio: File → Project Structure → SDK Location

**Error: "Gradle sync failed"**
- Open Android Studio
- File → Sync Project with Gradle Files
- Or: `cd android && ./gradlew clean`

**Error: "Cannot resolve symbol"**
- File → Invalidate Caches / Restart in Android Studio

### Runtime Errors

**App crashes on launch**
- Check Android Studio Logcat for errors
- Verify Firebase config is correct
- Check network permissions in `AndroidManifest.xml`

**Web assets not updating**
- Run `npm run cap:sync` after every build
- Clear app data: Settings → Apps → Household Routine Manager → Clear Data

### Capacitor Issues

**Plugins not working**
- Run `npm run cap:sync` to update plugins
- Check `android/app/src/main/assets/capacitor.plugins.json`

**Build fails**
- Delete `android/app/build` folder
- Run `npm run cap:sync`
- Rebuild in Android Studio
